
# GitHub Lab 6

## Giới thiệu
Đây là dự án thực hành quản lý phiên bản mã nguồn bằng Git và GitHub.

## Nội dung thực hành

- Tạo Commit
- Đưa dự án lên GitHub
- Tạo và quản lý Branch
- Tạo Pull Request
- Thực hiện Merge

## Công cụ sử dụng

- Visual Studio Code
