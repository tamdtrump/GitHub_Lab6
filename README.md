
# GitHub Lab 6

## Giới thiệu
Dự án thực hành quản lý phiên bản mã nguồn bằng Git và GitHub, kết hợp thay đổi từ nhánh main và feature.


## Nội dung thực hành
- Khởi tạo Git Repository
- Tạo Commit
- Đưa dự án lên GitHub
- Tạo và quản lý Branch
- Tạo Pull Request
- Thực hiện Merge

## Công cụ sử dụng
- Git
- GitHub
- Visual Studio Code
