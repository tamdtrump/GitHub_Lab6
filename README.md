
# GitHub Lab 6

## Giới thiệu
Dự án thực hành quản lý phiên bản mã nguồn bằng Git và GitHub, kết hợp thay đổi từ nhánh main và feature.


## Nội dung thực hành
- Khởi tạo Git Repository
- Tạo Commit
- Đưa dự án lên GitHub
- Tạo và quản lý Branch
- Tạo Pull Request
- Thực hiện Merge

## Công cụ sử dụng
- Git
- GitHub
- Visual Studio Code

## Thực hành Git trên Visual Studio Code

Các thao tác thực hành:
- Tạo Branch bằng giao diện VS Code
- Chỉnh sửa và Stage file
- Tạo Commit
- Push lên GitHub
- Tạo Pull Request
- Merge thay đổi vào main
